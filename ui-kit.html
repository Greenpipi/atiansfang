01

设计主张

Principles

这是每天要开几十张、打几十张的工具，界面不该抢戏。统一的方向是「纸笺墨绿」： 屏幕像一张干净的处方纸，绿色只用来指路，朱砂只在需要停一下的地方出现。

P.01
纸

纸感优先

底色是微微发暖的纸白，而不是冷灰面板。容器用发丝边框与极淡阴影分层，不做浮夸的玻璃拟态，让药名与数字成为页面里唯一的高对比信息。

底：暖纸 + 极淡纸纹 界：1px 发丝线，替代色块分区
P.02
墨

墨色克制

全站只有一个主动作色：深墨绿。用于主按钮、命中药名、合计金额。朱砂只做警示、发药标记与印章，不参与常规装饰，避免「满屏红绿」。

主：深墨绿 #14532D 警：朱砂 #A63A2B（面积不超过 5%）
P.03
数

数字可读

药名左对齐、金额右对齐、等宽数字。列宽与行高按 8pt 节奏，表头用小型大写间距标签；同一张表在屏幕、A5 打印、分享图片上都保持同一套对齐规则。

数字：等宽 + tabular-nums 对齐：名左价右，永不居中金额
02

Tokens · Type

03

基础控件

Components

按钮、输入、分段、标签全部收敛到同一套高度（32 / 36 / 40）与圆角。 主按钮永远只有一个，其余动作用描边或幽灵样式；危险动作改用朱砂色，而不是原来的正红。

按钮 Button01 / 05
图标按钮在静止时无边框；悬停只改变图标与底色，不位移、不加投影，避免像旧版一样在标题下压线。
表单 Form02 / 05
输入框统一 40px 高、圆角 6px；聚焦只用淡绿光环，不再叠加粗描边。搜索框带 / 快捷键提示，方便老手免鼠标操作。
分段 · 选择03 / 05
勾选项目右移出金额输入框；切换状态用分段，不用下拉，减少一次点击。
标签 · 状态04 / 05
已发药 未发药 缺药 自备 先煎 后下 另包 共 3 味
药味后缀（先煎/后下/另包）沿用浅描边标签；只在药名旁出现，不进入合计区。状态色仍以墨绿/朱砂为主，不新增第三种高饱和色。

08

迁移与落地

Rollout

现有页面里同一类控件被多层带 !important 的样式反复覆盖，颜色与圆角难以统一。 建议只换「令牌 + 控件层」，不动业务逻辑与数据结构，分三步上线。

令牌映射MAPPING
用途现有新令牌说明
页面背景linear-gradient 多段绿--paper #F3F1E8改暖纸底，去掉背景渐变冲突
主色--pri / --g-500 #16A34A--green #14532D降饱和、加深，适合小字号与打印
卡片背景--card / --n-white--card #FFFDF6白里带一点纸黄，减轻冷感
分隔线--line / --n-2 / #c9ddd1--line #D8D5C6统一暖灰，不再混冷灰
危险 / 发药#c00 / --danger--seal #A63A2B朱砂色，降低刺眼度
圆角3 / 4 / 10 / 16px 混用5 / 6 / 3px纸卡 5px，控件 6px，标签 3px
STEP 01

先换底色与令牌

只替换 :root 变量与 body 背景，不改布局。风险最低，一眼就能看出方向对不对。

  • 纸底 · 墨绿 · 朱砂
  • 统一圆角与线宽
  • 保留现有逻辑
STEP 02

再收控件层

按钮、输入、表格、面板换成新控件规格，删掉多层 !important 覆盖，建立单一来源。

  • 主按钮唯一
  • 表格对齐规范
  • 空态 / 提示统一
STEP 03

最后统一出图

处方笺、订单图片、结款明细套用同一令牌，三种模板共用数据与列宽，避免屏幕与图片两套长相。

  • 模板 A/B/C
  • 2x 出图不失真
  • 打印态同步
